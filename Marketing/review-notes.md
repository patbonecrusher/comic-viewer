# App Review notes

1. Screen recording: see attachment. Flow: launch → main features → Settings → quit.
2. Purpose and audience: Comic Viewer is a reader for comic files the user already owns (CBZ, CBR, PDF, folders of images). It is for comic readers on the Mac. It shows comics page by page or panel by panel, and keeps a library of the user's comic folders with covers and reading progress.
3. Setup and access: no account or login. Launch the app and choose File > Open to open any CBZ, CBR or PDF comic, or File > Add Folder to Library to add a folder of comics to the library. View > Panel by Panel steps through panels; View > Edit Panels opens the panel editor.
4. External services: none. Only Apple system frameworks. No network requests, analytics, accounts, payments or AI services.
5. Regional differences: none. Identical functionality in all regions; English only.
6. Regulated industry / third-party material: not applicable. All code and artwork are original. The app contains no comics; users open their own files.
